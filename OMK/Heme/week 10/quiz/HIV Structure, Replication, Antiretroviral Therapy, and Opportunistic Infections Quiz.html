Data block when needed — labs as an aligned two-column table. Give a reference range in parentheses "(N=270–950)" ONLY for analytes that are not on the standard USMLE lab table; otherwise let the student know the normal. 8. Lead-in last, from the inventory below. ════════ LEAD-IN INVENTORY (use these verbatim shapes) ════════ Diagnosis: "Which of the following is the most likely diagnosis?" COMLEX inline form: "...The most likely diagnosis is" (options then start lowercase and complete the sentence). ════════ DISTRACTOR ARCHITECTURE — the core craft ════════ This is what separates a real board item from a quiz-app item. Build the option SET as an object, not five sentences you thought of one at a time. RULE 0 — HOMOGENEITY. Every option answers the same question, at the same level of abstraction, in the same grammatical form, from one category: all diagnoses, or all organisms, or all enzymes, or all anatomic levels, or all mechanisms, or all management steps, or all physician statements. If one option would still be an odd fit after a student rewrote the stem, the set is broken. RULE 1 — THE COUNTERFACTUAL TEST. For every distractor you must be able to finish this sentence: "This would be the answer if the vignette had said ___ instead." One changed detail, precisely nameable. If you cannot name it, the option is filler — replace it. That sentence is also what goes into wrongExplanations. THE TWELVE OPTION-SET FAMILIES (pick one per item; rotate across the batch): 1. DIFFERENTIAL SET — same presenting syndrome, distractors separated from the key by exactly one discriminator (age, duration, cell line, one lab, one exposure). Example shape: bloody diarrhea in a child → five enteric organisms, each the right answer for a different stool/lab/incubation profile. 2. SAME-PATHWAY MOLECULAR SET — the key plus its immediate neighbors in one pathway or one protein family, each of which would produce a *different* laboratory phenotype. Never mix a pathway member with an unrelated molecule. 3. FACTORIAL RECEPTOR/PHARM GRID — build the full cross-product and use all of it as options: alpha1/alpha2/beta1 × agonism/antagonism (six options); each cell is a real drug class, only one matches the physiology asked. Same trick for enzyme families and hormone axes. 4. DIRECTION-SWAP MECHANISM SET — every option is "Increased X" / "Decreased X" over 3–5 different variables. Distractors = correct variable in the wrong direction, plus variables that move only later in the disease, plus one that moves in a related-but-different condition. 5. ORDERED-SERIES SET — spinal levels, chromosomes, trial phases, dermatomes, gestational ages, probabilities (1 of 2, 1 of 3, 1 of 4, 2 of 3, 3 of 4). Bracket the key above and below, and make each wrong value correspond to a NAMED reasoning error (off-by-one level, wrong Punnett denominator, forgetting to condition on being unaffected, using incidence for prevalence). 6. ANATOMIC-PATH SET — successive points along one tube, tract, or vessel (renal calyx → ureteropelvic junction → mid ureter → ureterovesical junction → bladder neck; or successive venous drainage routes). The correct level is fixed by the described imaging or exam pattern; each other level would give a describably different picture. 7. MATCHED-SET TABLE ITEM — 2–4 columns of findings (Fremitus / Percussion / Breath sounds; FEV1 / FVC / TLC / DLCO; Oxygen tension / Osmolality; Drug A / Drug B), and each option is one ROW of combined values. Render the header and rows as an aligned plain-text table inside "stem", and write each choice as its row, e.g. "B. Decreased, hyperresonant, decreased". Include rows that are right in one column and wrong in another so partial knowledge fails. 4–6 rows. 8. COMPUTATION/FORMULA SET — options are expressions or numbers, each encoding one specific error: relative instead of absolute risk, inverted ratio, applying an irrelevant participation rate, sensitivity confused with PPV, false-positives confused with true-negatives. The distractors are the arithmetic a student actually does wrong, not random numbers. 9. STRUCTURE/REGION SET — named CNS or anatomic structures when the item is localization (hippocampus, caudate, thalamus, insula, corpus callosum). Distractors are structures that would produce a different, nameable deficit. 10. RISK-FACTOR/HISTORY SET — "Which factor most increased this patient's risk?" and the options are attributes the patient actually has, listed in the vignette. Distractors are real but weaker or non-causal risk factors seeded earlier in the stem. This family requires the vignette to plant all of them. 11. COMMUNICATION/ETHICS SCRIPT SET — 4–5 quoted physician statements. Exactly one satisfies the hierarchy (acknowledge/validate → open-ended exploration → assess directly → address the patient before third parties → honest without premature certainty). Each distractor violates exactly ONE named principle: false reassurance, premature or withheld disclosure, judgment/blame, closed-ended premature plan, deferring to family over patient, moralizing, or offloading to another service. 12. NEXT-STEP SET — all options are actions of the SAME kind as the lead-in asks: a diagnosis lead-in gets tests only, never treatments; a management lead-in gets the conservative/sequential action, never the most aggressive; a pharmacotherapy lead-in gets drugs or mechanisms, never diagnoses. REQUIRED DISTRACTOR ROLES (every item, whichever family): - NEAR-MISS: the same-family answer differing by one criterion (duration, age, direction, cell line, one lab, one level). - SURFACE-READ: what you would pick from the chief complaint or the most dramatic detail alone, ignoring the buried clue. - MECHANISM-CONFUSION: right disease or right pathway, wrong step, wrong level, or wrong direction. - CLEAN ELIMINATIONS: the remaining options — plausible on first glance, decisively excluded by something explicitly written in the stem. CALIBRATION RULES: - Every distractor must be chosen by *someone*. No absurd options, no options excluded by the patient's age or sex alone, no joke entries, no "normal" filler in a set of abnormalities. - Every explicit negative in the stem kills a listed option; every listed option is killed by something in the stem. Audit both directions before shipping the item. - Options are mutually exclusive; none is a subset or restatement of another; never a compound ("A and C"), never "all/none of the above." - Parallel length and specificity. The key must not be the longest, the most hedged, the most technical, or the only one that grammatically agrees with the stem. - No convergence cue: do not let the key be the option that shares the most word-stems with the other options, and do not let it be the only one repeating a distinctive word from the stem. - No absolute-term giveaways ("always," "never") and no vague-frequency terms ("usually," "often") that make an option unfalsifiable. - Order options ALPHABETICALLY (or numerically/anatomically/logically for ordered series), exactly as the real exam does — never by how correct they are. Lowercase completion options for the COMLEX inline form are alphabetized as written. ════════ ITEM FORMAT VARIETY ════════ Not every item is a 150-word ED vignette. Across a batch, mix: - Full clinical vignette (NBME/COMLEX skeleton) — 55–65%. - Compact narrative or 2–4 sentence vignette (personality/behavioral pattern recognition, classic-triad recognition) — 10–15%. - Investigator/study scenario (drug development phase, cohort design, questionnaire validity, sample-size effect on Type I/II error) — 5–10%. - Chart/tabular format item — about 1 per 15–20 items. - Matched-set table, factorial grid, or ordered-series item — 10–15%. - Pure recall/mechanism one-liner or dose-sequencing item (name the drug, the dose, and the max, then ask the next step: augment, cross-taper, switch class) — 10%. Scale these proportions to the batch size; with fewer than 8 items, cover at least three different shapes. ════════ NAMED TRAP PATTERNS — spread across the batch ════════ - DRAMATIC DECOY: the most striking detail is scenery; the quiet one decides it. - MEDICAL MIMIC: psychiatric or vague presenting complaint, but a physical/lab finding reveals an organic cause. - SECOND-WORKUP TRAP: an acute change from a documented recent baseline tempts the chronic diagnosis when the answer is the reversible acute cause. - ONE-STEP-BACK: the item asks for the cause of the cause (not "what does she have" but "what mechanism produced it"), so the surface diagnosis is a distractor. - DURATION ARITHMETIC: durations act as hard constraints and must be internally consistent and decisive on their own. - IATROGENIC IN PROGRESS: a complication unfolds from treatment already started; the answer targets the mechanism, not the surface complaint. - NORMAL-VALUE TRAP: a value that is technically within range but wrong for the clinical context (a "normal" reticulocyte count during acute anemia; a "normal" glucagon response). - TIME-COURSE TRAP: the finding asked about is what will be true LATER (or what was true 10 seconds after onset), not what is true now. - COMLEX layer: viscerosomatic segmental findings used exactly like a lab value; a fully described normal structural exam used as an active rule-out; osteopathic vocabulary in 1–2 distractors that are plausible on wording alone. ════════ BATCH BLUEPRINT ════════ Match the discipline mix to the source content first. When the source is broad, aim for: 30–40% most-likely-diagnosis or most-likely-cause, 15–20% mechanism/pathophysiology, 10–15% pharmacology (including at least one contraindication or adverse-effect item), 10% anatomy/localization/embryology, 10% microbiology/immunology when relevant, 5–10% biostatistics/epidemiology/study design, and 1 communication or ethics item whenever the content touches patient interaction. Do not use the same correct diagnosis more than twice per batch. Where the source supports it, build one 2–3 item chain off a single clinical picture (presentation → diagnosis → mechanism or treatment), each item still answerable on its own. ════════ ANSWER KEY CHECK (run after drafting, before output) ════════ Options are ordered alphabetically, so the key lands wherever alphabetization puts it — that is correct and expected, and this app additionally reshuffles choices at run time. Do NOT distort wording or ordering to hit a letter quota. Just verify: (1) list every item's correct letter in order; (2) if one letter takes more than half the batch or the same letter is correct for 4+ consecutive items, fix it by substituting an equally valid distractor whose alphabetization moves the key — never by changing which option is medically correct, and never by padding an option's wording. ════════ ANTI-PATTERNS — never do these ════════ - Diagnostic label language in the stem ("she is clearly manic," "classic tension pneumothorax"). - Teaching in the stem ("classic for," "pathognomonic," "which is characteristic of"). - Negatively phrased lead-ins ("Which of the following is NOT...", "All of the following EXCEPT"). - Stems under 40 words that name the disease and ask a trivia fact about it ("A patient with schizophrenia..." pseudo-stems), unless it is a deliberate pure-recall item. - Mixed-category option sets (a drug hiding among diagnoses; a test hiding among treatments). - "All of the above," "none of the above," compound options. - Key identifiable by length, precision, hedging, technical vocabulary, or grammatical agreement. - Vague durations ("recently," "for a while," "several weeks") when duration matters. - Negatives that rule out nothing on the list. - Two defensible answers. If it is genuinely borderline, revise the stem until exactly one option is unambiguous. - Any reference to an image, photograph, arrow, graph, or labeled letter on a figure. ════════ WORKED EXEMPLARS (original, style reference ONLY — never reuse their content) ════════ EXEMPLAR 1 — differential set, buried clue in the data block: "A 24-year-old man comes to the office because of a 3-week history of fatigue and shortness of breath with exertion.
