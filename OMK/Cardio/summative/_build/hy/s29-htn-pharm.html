Antihypertensives & Electrolytes

  • First line: ACEi/ARB, DHP CCB, thiazide. Stage 2 <75 not frail → two drugs in one pill (DHP CCB + ACEi/ARB). Monotherapy is undone by baroreflex + renin.
  • Comorbidity picks: stones/osteoporosis → thiazide · CKD albuminuria → ACEi/ARB · AF → β-blocker or non-DHP CCB · pregnancy-possible → DHP CCB · BPH → α1 blocker.
  • ACEi: ↓AT II + ↑bradykinin → cough (predicts angioedema), angioedema, ↑K⁺; enalapril prodrug. ARB: no bradykinin. Avoid ACEi+ARB, β-blocker+verapamil/diltiazem, two sympatholytics, RAASi in pregnancy.
  • DHP CCB: edema (not fixed by diuretic), reflex tachycardia (nifedipine). Verapamil heart → diltiazem → dipines vessels.
  • Pregnancy: labetalol, nifedipine ER, methyldopa (hydralazine acute). Avoid ACEi/ARB/aliskiren, nitroprusside, spironolactone, atenolol.
  • Electrolytes: thiazide ↓Na ↓K ↑Ca ↑urate ↑glucose, alkalosis · loop ↓K ↓Mg ↓Ca, alkalosis · ACEi/ARB/aliskiren ↑K · MRA ↑K + hyperchloremic acidosis (spironolactone gynecomastia) · amiloride ↑K + acidosis · acetazolamide ↓K + acidosis.
  • Mechanism: more distal Na⁺ → ENaC → lumen negative → K⁺ and H⁺ out. Block aldosterone/ENaC → K⁺ and H⁺ stay.
